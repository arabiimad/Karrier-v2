Questions fréquentes

Faut-il être client ?

Non. Le programme ambassadeur est ouvert à tous, sur validation de l'équipe.

Quand est-ce que je gagne ?

Quand la personne qui a commandé avec votre code a réglé sa commande. Si la commande est remboursée, le gain est retiré de votre solde.

Comment je récupère l'argent ?

Depuis votre espace : virement de tout le solde sur votre compte bancaire, sans minimum, ou code de réduction pour votre propre abonnement.

Je suis déjà client. Je peux aussi être ambassadeur ?

Oui. Votre code de parrainage client et votre code ambassadeur sont séparés, avec chacun son solde.
